# M1 — Manual test checklist

Automated (all passing): `npm run check` → 40 unit/component tests; `npm run e2e` → 20 end-to-end tests
(desktop + Pixel 7, production build) covering onboarding, tasks, sections, trash, tags, backup/erase/import and offline writes.

Tick these on your own devices before signing off M1.

## First run

- [ ] Open the app on a fresh browser (or Settings → **Erase…**). You land on **setup**.
- [ ] Pick **Researcher**, enter research areas (e.g. _Physical AI_) and courses (e.g. _SMAI_).
- [ ] On **Your sections**, untick something you don’t need and rename something. The result matches after setup.
- [ ] Today greets you by name.

## Sections

- [ ] Sidebar **＋** (desktop) or Sections tab **＋** (phone) → create a section with an icon and color.
- [ ] Section page **⚙** menu: edit, add subsection, hide, delete. Hidden sections disappear from navigation but stay in **Settings → Sections**.
- [ ] Settings → Sections: move items up/down; use **Edit → Inside** to nest a section under another.
- [ ] Delete a section with tasks → **Trash** shows it with “+N tasks” → **Restore** brings everything back.

## Tasks

- [ ] Add tasks from a section page and from **All Tasks**.
- [ ] Tick a task → it leaves _Open_ → **Undo** in the toast brings it back.
- [ ] **⋯ → Skip…** with a reason → it appears under _Skipped_, never under _Completed_.
- [ ] Task editor: due date in the past → red **Overdue**; choose **AoE** for a conference deadline; priority; tags; subtasks; notes.
- [ ] History at the bottom of the editor lists what you changed.
- [ ] Close and reopen the app → everything is still there.

## Data safety

- [ ] Settings → **Download backup** → a `personal-os-backup-YYYY-MM-DD.json` file downloads; “Last backup: Today”.
- [ ] Settings → **Export CSV** opens in Excel/Google Sheets.
- [ ] Settings → **Import…** the backup → **Merge** reports “0 added …” (nothing duplicated).
- [ ] On your phone: Airplane mode → add a task → it saves; turn the network back on → still there.
