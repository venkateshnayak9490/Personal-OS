# M1 — Manual test checklist (with the UI refresh)

Automated (all passing): `npm run check` → 43 unit/component tests; `npm run e2e` → 22 end-to-end tests
(desktop + Pixel 7, production build) covering setup, the New task sheet, tasks, sections, trash, tags,
backup/erase/import, offline writes and error screens.

Tick these on your own devices before signing off M1. On your phone, open the app and tap **Reload** when it
says a new version is ready (or close and reopen it once).

## First run (Settings → Erase… to see it again)

- [ ] One screen: your name and what you do, both optional. **Get started** takes you straight to Today.
- [ ] **Finish setting up** on Today: add research areas (e.g. _Physical AI_) and a course (_SMAI_). Each one
      ticks itself off. **Hide** removes the checklist.

## Adding tasks (the main thing to judge)

- [ ] Phone: the round **＋** opens **New task**. Type, press Enter on the keyboard. It says where it went, and
      you can type the next one straight away.
- [ ] Open a section (e.g. Research), tap ＋: tasks go to that section. On Today they're due today.
- [ ] Chips: change the section, Today / Tomorrow / Date, and Priority without opening the editor.
- [ ] Desktop: **New task** in the sidebar, or press **N** anywhere.
- [ ] All Tasks: filter by a section, add a task. It goes to that section and stays visible.

## Phone feel

- [ ] Opening sections, tasks and ＋ never shows a black screen. If anything goes wrong you should now see an
      error message instead. Then go to **More → Settings → Copy diagnostics** and send me the text.
- [ ] Text is readable without zooming; buttons and checkboxes are easy to hit with a thumb.
- [ ] Tick a task: it checks off, stays for a moment, then leaves. **Undo** in the message brings it back.

## Still from M1

- [ ] **⋯ → Skip…** with a reason → it appears under _Skipped_, never under _Completed_.
- [ ] Task editor: due date in the past → red **Overdue**; **AoE** for a conference deadline; history at the
      bottom lists changes. Start date, type and estimate are under **More details**.
- [ ] Delete a section with tasks → **Trash** → **Restore** brings everything back.
- [ ] Settings → **Download backup**, **Export CSV**, **Import…** (Merge reports nothing duplicated).
- [ ] Airplane mode → add a task → it saves.
