# M0 — Manual test checklist

Automated: `npm run check` (types, lint, unit tests) and `npm run e2e` (desktop + Pixel 7, production build, offline) all pass.

These need a real device or a human eye. Tick each one before signing off M0.

## Laptop (Chrome)

- [ ] `npm run dev` → open http://localhost:5173. Dark theme by default, no white flash on load.
- [ ] Sidebar: expand/collapse Work, Self-Improvement, Personal Life, Miscellaneous; every link opens a page.
- [ ] Collapse the sidebar (icon at the top right of it) → icon rail; reload → stays collapsed.
- [ ] Narrow the window below ~1024px → sidebar becomes an icon rail; below 768px → bottom tab bar.
- [ ] Quick Capture button opens the sheet; Esc closes it.
- [ ] Settings → Theme: Light / Dark / System all work and survive a reload.
- [ ] `npm run build && npm run preview` → open http://localhost:4173 → Chrome address bar shows the **Install** icon → install → app opens in its own window with the Personal OS icon.
- [ ] In the installed app, DevTools → Network → Offline → reload → the app still loads.

## Android phone (Chrome) — after the first Vercel deploy

- [ ] Open the Vercel URL → menu → **Install app** (or Add to Home screen). The icon appears on the home screen.
- [ ] Launch from the icon → opens full screen (no browser bar), status bar color matches the theme.
- [ ] Bottom bar: Today, Calendar, ＋, Sections, More are all reachable with your thumb; the ＋ opens Quick Capture as a bottom sheet.
- [ ] Turn on Airplane mode → open the app → it still loads and navigates.
- [ ] Settings → Persistent storage shows **Protected** after installing (if not, tap Request protection).
- [ ] Rotate the phone → layout adapts, nothing cut off.
