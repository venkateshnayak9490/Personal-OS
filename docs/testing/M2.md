# M2 — Manual test checklist (desktop first)

Test on the **desktop app** (installed from Chrome). The phone gets its own design later.

## Done so far

### Notion-style pages

- [ ] Open any section (e.g. Research). Click the line under the title and type.
- [ ] Markdown shortcuts: `# ` heading 1, `## ` heading 2, `- ` bullets, `1. ` numbers, `[] ` checklist,
      `> ` quote, `---` divider.
- [ ] Type `/` → a menu of blocks; arrow keys + Enter, or click.
- [ ] "Saved" appears top-right after you stop typing. Close and reopen the app → the page is still there.
- [ ] Delete the section → Trash → Restore: the page comes back with it.

### Date picker

- [ ] In any "Add a task" box, type a title, click **Date**: Today / Tomorrow / This weekend / Next week, or
      a day in the calendar. One click, then press Enter to add.
- [ ] In the task editor, **Due date** and **Start date** use the same picker.

### Hiding sections

- [ ] Hover a section in the sidebar → the eye icon hides it (Undo appears).
- [ ] **Hidden (N)** at the bottom of the sidebar list → the eye shows it again.

### Inbox and plain-language capture

- [ ] Type in any "Add a task" box: `Submit review fri 5pm #thesis !high @research`. The **Understood** line shows
      the date, priority, tag and section before you press Enter. Click × on any part to keep it as plain text.
- [ ] Also try: `tomorrow 11am`, `next monday`, `in 3 days`, `nov 30 aoe`, `!urgent`, `!low`.
- [ ] Tasks without a section go to **Inbox** (sidebar shows how many). **Move to…** on each row sorts them.

### Search (Ctrl+K)

- [ ] Press **Ctrl+K** anywhere (or the 🔍 button): find tasks, sections and text inside pages; arrow keys + Enter.
- [ ] Type something that isn't found → **Add task: …** adds it where you are (with the same plain-language parsing).

### Repeating tasks

- [ ] Capture `Gym every monday 7am` (or set **Repeat** in the task editor).
- [ ] Tick it: "Next one: Mon …" appears and the next occurrence is in the list. **Undo** removes it again.
- [ ] Skipping also moves on to the next one, and still never counts as done.

### Projects

- [ ] Sidebar **Projects** → **New project** → name it. You land on the project page.
- [ ] Add tasks there; tick one → the bar shows honest progress (only completed counts; skipped stays in the total).
- [ ] Milestones on the right; **Progress from** can be Tasks, Milestones or set by hand.
- [ ] Status, section, goal and due date at the top. A task's editor also has a **Project** field.

### Goals

- [ ] **Goals** → **New goal**. Optional measure (e.g. 0 / 30 papers) with + and − buttons.
- [ ] Without a measure, progress is the average of the projects linked to the goal.

### Habits

- [ ] **Habits** → **New habit**: every day, N times a week, or specific days. Rest days optional.
- [ ] Click a day: done → skipped → rest day → clear. Streak (flame) and "this week" update.
- [ ] Today shows **Habits today** with one-click check-in.

### Calendar & events

- [ ] Sidebar **Calendar**: Month, Week and Day views. Tasks with a due date show with a small checkbox.
- [ ] Drag across the week grid (or click a day in Month) → **New event**. Set repeat, reminder, section, place.
- [ ] Click an event to edit or delete it (Delete → Trash, with Undo). Drag a one-off event or a task to move it.
- [ ] A repeating event shows on every matching day (repeats can't be dragged; edit the series instead).

### Reminders (only while the app is open)

- [ ] Add a task due a minute from now, e.g. `Call home today 6:05pm`. At that time a reminder card appears
      bottom-right. **Open** opens the task, × dismisses it. It does not come back after a reload.
- [ ] Events remind at the time you chose (10 minutes before by default).
- [ ] Settings → App → **Allow notifications** to also get a system notification while the tab is in the background.

### Today

- [ ] Today shows today's events, today's tasks, habits, **Coming up** (next 7 days), active projects and your areas.
- [ ] **Customize Today** (bottom of the page): hide or reorder these. Saved on this device only.

### Motivational messages

- [ ] A short line under the greeting and under each section's title; × hides it for this visit.
- [ ] Settings → **Messages**: add your own lines (anywhere, or for one section), delete them, or turn messages off.
